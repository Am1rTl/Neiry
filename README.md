# NeuroScope

Локальная исследовательская лаборатория для записей Neiry Capsule: ЭЭГ, ФПГ, движение и контакт электродов. Интерфейс и документация на русском. Исходный код и исследовательская база находятся в репозитории; персональные записи и рассчитанные на их основе отчёты в публичный GitHub не публикуются.

## Обновление: лаборатория V2

Теперь в одной теме доступны расширенный живой монитор со спектрограммой и контролем качества, воспроизведение без полной загрузки записи в память, исследование выбранного участка и аннотации, управляемые эксперименты, история сопоставимых сессий, локальный PDF и опциональный экспорт EEG-BIDS. Метрики Hjorth и описательный спектральный наклон рассчитываются только для пригодного сигнала.

**Важное исправление Capsule SDK:** обход `DeviceInfoList` сделан по `range(len(info))`: несуществующий индекс больше не запрашивается, предотвращая известный SIGSEGV в `clCDeviceInfo_GetName(NULL)`. Для завершения сервера `stop.sh` использует SIGINT вместо SIGTERM, поскольку сторонняя нативная библиотека может перехватывать SIGTERM. Физический SDK необходимо дополнительно проверить на конкретной повязке.

[Подробно: обновление V2, инструкции и ограничения](docs/UPGRADE_V2.md).

## Запуск и локальные записи

После `git pull` запускайте `bash start.sh --open` (Linux/macOS) или `start.bat` (Windows). Приложение открывается без устройства и без калибровки. Данные записей находятся **только на вашем компьютере** в `records/` и не включаются в публичный репозиторий. Если у вас уже есть записи, оставьте их в `records/`: обновление Git их не затронет.

Для нового клона каталог `records/` создаётся автоматически при первом запуске. Экспорт JSON/CSV/HTML и автономная версия создаются локально из ваших файлов, а не публикуются в GitHub.

## Запуск приложения

Рекомендуется Python 3.12; проверено с Python 3.12.14. Интернет нужен только для первоначальной установки зависимостей. Сам анализ работает локально и не требует аккаунта, API-ключа или облачной модели.

### Linux / macOS

```bash
cd NeuroScope
bash start.sh --open
```

Скрипт создаёт `.venv`, устанавливает зависимости при их отсутствии и запускает приложение в текущем терминале. Откройте http://127.0.0.1:8000. Для завершения нажмите Ctrl+C; в другом терминале можно выполнить `bash stop.sh`.

### Windows: анализ архива

Установите Python 3.12 с добавлением в PATH и запустите `start.bat`. Или выполните:

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python run.py --open
```

Аппаратная интеграция, перенесённая из оригинала, использует Linux-библиотеку Capsule `.so`. Для подключения устройства в Windows/macOS нужна соответствующая адаптация поставки SDK; офлайн-анализ архива от этого не зависит. Проверка с физической повязкой в этой среде не выполнялась.

### Ручной запуск / другой порт

```bash
python -m pip install -r requirements.txt
python run.py --port 8001
python run.py --analyze
```

`--analyze` перед запуском проверяет кэш по содержимому файлов и пересчитывает изменённые записи. Прямой запуск `python server.py` также работает. Адрес по умолчанию ограничен `127.0.0.1`.

## Разделы

- **Обзор**: выбор записи, качество, доказуемые наблюдения, ограничения, контекст пользователя.
- **Сигналы**: исходный фрагмент, спектр до и после скрининга, полосы, временные показатели, ФПГ, движение и контакт.
- **Сравнение**: описательное сопоставление сессий с явными знаменателями. Без диагнозов и популяционных норм.
- **Научная база**: 17 разделов, 22 метрики, 25 первичных/официальных источников.
- **Протокол**: четыре способа собрать более интерпретируемые данные в будущем.
- **Устройство** (`#device`): ручной поиск и выбор обнаруженной повязки, реальная проверка соединения, управление отключением/переподключением и необязательной калибровкой.
- **Живой монитор** (`#live`): ЭЭГ, пульсовая волна, акселерометр, контакт, показатели SDK, ручная запись и метки событий — в новой теме, без перехода на старую страницу.
- **Записи и replay** (`#sessions`): список сессий, воспроизведение архива без устройства, анализ, экспорт ZIP и удаление.

Все эти разделы находятся **в одной странице**. Старые ссылки `/live`, `/charts` и `/sessions` ведут в соответствующие разделы общей оболочки. Метрики SDK помечены как модельные оценки. Подробнее — `docs/UNIFIED_INTERFACE.md`.

Поля контекста заполняются ретроспективно: они не заменяют синхронные event markers и не меняют численные расчёты. Экспорт отдельной сессии доступен в JSON, CSV и HTML. Общий исследовательский отчёт — в PDF.

## Как устроен автоанализ

1. Читает сохранённые CSV и JSONL; проверяет полноту, индексы, время, конечность чисел, квантование.
2. Анализирует ЭЭГ в порядке отсчётов при частоте из metadata. Обратные шаги callback-времени не исправляются сортировкой данных.
3. Считает спектры окон с правильной односторонней нормировкой, проверяет артефакты и формирует явные причины исключения.
4. Выдаёт полосовую мощность и кандидат пика только при достаточных данных. Отсутствие результата отображается как отсутствие, а не ноль.
5. Оценивает пульс/исследовательскую PRV с отдельной проверкой качества. PRV по ФПГ не равна ЭКГ-HRV.
6. Описывает движение, контакт, калибровки и выходы SDK, сохраняя их происхождение.
7. Формирует воспроизводимый JSON с версией метода, параметрами, SHA-256 и ограничениями.

Анализ запускается при открытии записи, по кнопке пересчёта и в фоне после штатного завершения новой записи. Если приложение выключилось до завершения фоновой задачи, при следующем открытии запись будет обработана. Кэш инвалидируется по версии метода и содержимому входных файлов; вычисления вынесены из web event loop.

Доля прошедших окон — результат инженерных эвристик с перекрытием, не процент здорового мозга, не вероятность отсутствия артефактов и не точная доля чистого времени. Все пороги опубликованы в JSON. Порог 50 Гц и диапазоны частот не являются диагностическими нормами.

## Добавить запись

Поместите каталог `session_*` в локальную папку `records/` (не хранится в Git). Ожидаются `meta.json` с `sample_rates` и `channels`, `eeg.csv`, необязательные `ppg.csv`, `mems.csv`, `resistances.csv`, `metrics.jsonl`, `events.jsonl`. Пустые потоки допустимы. Пример структуры доступен в документации и коде; записи пользователей не хранятся в Git.

```bash
python analysis_engine.py --all --records records --output reports
python analysis_engine.py --all --records records --output reports
python scripts/build_preview.py
```

Физические единицы и масштаб необходимо подтвердить по вашей версии SDK. Новые записи сохраняются без прежнего округления EEG, с описанием происхождения времени. Аппаратные timestamp/counter исходный SDK-адаптер пока не предоставляет: восстановить синхронизацию из одного времени доставки невозможно.

## Подключение повязки

```bash
CAPSULE_SDK_DIR=/path/to/CapsuleAPI/Linux bash start.sh
```

Capsule SDK не включён в ZIP: в предоставленном проекте нет рабочей поставки нативной библиотеки. Нужна собственная поставка производителя. Приложение **запускается без устройства**: архив, анализ и replay доступны сразу. Откройте вкладку «Устройство», нажмите «Найти устройство» и выберите подтверждённый серийный номер; подключение не запускается автоматически. Калибровка возможна **только после подключения** и выполняется по явной команде пользователя. Запись запускается кнопкой «Начать запись» и не начинается при обычном подключении. Вернуть прежний автозапуск записи можно через `RECORD_ENABLED=1`. При отключении потоковые данные сбрасываются; автопереподключение выключено по умолчанию и настраивается в интерфейсе. Пошаговые инструкции — `docs/UNIFIED_INTERFACE.md`, настройки — `config.py`.

## Проверка

```bash
python -m pip install -r requirements-dev.txt
python -m unittest discover -p 'test_*.py' -v
```

Тестируются нормировка PSD (сохранение дисперсии), известные частоты, отсутствие/нечисловые данные, пропуски индекса, сетевые помехи, квантование, pulse/PRV, сохранение точности, strict JSON и API. Сам тестовый набор не является клинической валидацией алгоритма.

Для создания PDF из локальных записей: `python scripts/build_report.py`. Шрифты Open Sans/DejaVu ищутся в системных каталогах; персональные отчёты не добавляются в публичный Git.

## EDF: дополнительная возможность

Нужен `pyedflib`. Экспорт требует явного `--allow-approximate-timing`: он использует номинальную сетку и не восстанавливает аппаратное совмещение потоков. Неизвестные единицы сохраняются как `a.u.`, а не автоматически `µV`. Создаётся sidecar JSON с ограничениями. Для исследований времени предпочтительнее исходные CSV.

```bash
python edf_export.py records/session_... output.edf --allow-approximate-timing
```

## Границы интерпретации

Файлы содержат два биполярных отведения O1–T3/O2–T4. Это не карта функций всех отделов мозга. Приложение не определяет IQ, личность, «доминирующее полушарие», дофамин, диагнозы или лечение. Сведения о работе мозга в научной базе — общий контекст; конкретные выводы всегда относятся к измеренному сигналу и качеству записи.
