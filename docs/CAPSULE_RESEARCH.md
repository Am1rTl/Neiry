# Диагностика Capsule 2.0.72

## Что показывает NeuroScope

| Поток | Источник | Что проверить |
|---|---|---|
| ЭЭГ | Сырые отсчёты SDK и сопротивление электродов | Посадка повязки, контакт, пригодность окон в автоматическом разборе |
| Сырая ФПГ | Отсчёты оптического датчика | Поступают ли отсчёты. Сопротивление электродов ЭЭГ и оптический контакт SDK измеряют разные вещи. |
| Пульс и кардиоиндексы | Алгоритм Capsule | Оптический контакт, движение, флаги артефактов и доступность результата |
| Движение | Акселерометр и гироскоп SDK | Совпадают ли отклонения с этапом или подозрительным участком ЭЭГ |
| Продуктивность и физиологические оценки | Отдельные алгоритмы Capsule | Индивидуальная частота NFB и базовые калибровки. Для физиологических оценок SDK также требует базовый уровень продуктивности. |

Счётчик доставки WebSocket продвигается по количеству принятых отсчётов. Ось времени в браузере использует номинальный интервал дискретизации и сохраняет более крупные паузы между пакетами. При пакетной доставке она может расходиться с часами SDK и временной осью CSV. В CSV остаются времена, восстановленные по моменту доставки пакета, и индексы отсчётов. Для ЭЭГ доступны дополнительные метки Capsule в `eeg_batch_timing`.

Автоматический разбор при открытии записи показывает наличие потоков, пригодность окон, частые причины их отклонения, флаги артефактов и скачки времени между пакетами с последовательными индексами. Такие скачки позволяют найти участки для проверки, а для заключения о потере Bluetooth нужны измерения на устройстве с учётом свойств часов SDK. Физические единицы сигналов остаются единицами SDK, пока масштаб не подтверждён документацией или измерением. Графики подбирают диапазон по видимым отсчётам.

## Возможности Capsule и Mind Tracker

| Возможность | Что даёт для исследований NeuroScope |
|---|---|
| Версии прошивки и Capsule, физическая схема электродов, отдельные шкалы кардиографиков | Версии теперь появляются рядом с подключением и в метаданных новых записей. Все каналы сопротивления можно сравнивать на графике. |
| Публичные события PSD, индивидуальная частота и границы альфа-полосы | Можно сверить собственную оценку спектра с PSD Capsule. Публичные интерфейсы описаны в `CPSDData.h` и `CNFBCalibrator.h`. |
| SDK-время отсчётов ФПГ и MEMS, экспорт Capsule HDF5 | Подходящие кандидаты для проверки временной привязки между датчиками и сравнения записей двух программ. |
| Именованные интервалы и звуковая обратная связь в Mind Tracker | Метки действий пригодятся для повторяемых сравнений. Звуковую обратную связь можно проверить в отдельном протоколе с журналированием времени звуков. |

Публичный `CCardio.h` в версии 2.0.72 отдаёт сырую ФПГ, три кардиопоказателя и флаги качества. В настольном приложении есть дополнительные представления ФПГ. Их наличие в интерфейсе само по себе не подтверждает доступность через SDK.
