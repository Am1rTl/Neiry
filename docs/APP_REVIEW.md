# Аудит исходного приложения и изменения

## Главные проблемы и решения

| Наблюдение в исходнике | Почему важно | Что изменено |
|---|---|---|
| `record_eeg` сохранял `round(v, 4)` | Малые изменения теряются безвозвратно | Новые файлы сохраняют 17 значащих цифр исходного float. Старые файлы не меняются |
| В meta нет единиц и происхождения времени | Нельзя автоматически выводить микровольты или аппаратную синхронизацию | Версия формата 2, явно неизвестные SDK-единицы, происхождение callback timestamp |
| Прямой rFFT periodogram без удвоения внутренних частот | Абсолютная односторонняя мощность занижалась приблизительно вдвое | Исправлена нормировка, тесты мощности для чётных и нечётных длин |
| HRV считалась простым порогом по PPG без QC | Двойные/пропущенные пики создают ложную вариабельность | Новый pulse/PRV-анализ с окнами, отбрасыванием и отдельными условиями для PRV; live помечен экспериментальным |
| JSONL допускает NaN/Infinity | Не строгий JSON, ломает потребителей и выдаёт недоступное за число | Новые JSON-потоки используют null; исходные нечисловые данные учитываются в аудите |
| Некоторые будущие отсутствующие EEG-каналы дополнялись нулями | Ноль похож на реальное измерение | Отсутствующее значение сохраняется как NaN и получает флаг анализа |
| В старой когнитивной странице были самостоятельные выводы о депрессивном фоне, тревоге и дофамине | Пороговые индексы без валидации не подтверждают эти утверждения | Страница заменена научно корректным переходом; неподтверждённые классификаторы удалены |
| Имена SDK переименовывались в эмоции | cognitiveLoad не синоним стресса, cognitiveControl не синоним гнева | Подписи возвращены к исходному смыслу и помечены SDK |
| EEG timestamp строился заново в каждом callback | Возникают обратные шаги и неопределённость синхронизации | Анализ идёт по порядку отсчётов; происхождение времени явно документируется. Достоверные аппаратные часы не выдуманы |
| Нет единого анализа сессии | Пользователь видит набор графиков без проверки применимости | Добавлен воспроизводимый анализ EEG/PPG/MEMS/контакта/SDK с причинами ограничений |
| EDF объявлял сырые EEG числа микровольтами | Физическая шкала могла быть неверной; стандартные пределы writer могли отсечь значения | Неизвестная шкала a.u., динамический physical range, opt-in для приблизительного времени |
| `stop.sh` мог вызывать fuser/pkill для чужих процессов | Остановка приложения могла задеть другой сервис | Только PID этой копии и проверка команды процесса |
| Пути сессий и экспорт допускали символические ссылки | Чтение, ZIP или удаление могли затронуть другой каталог | Символические ссылки и обход каталогов отклоняются; мутации с чужого Origin запрещены |
| Данные/зависимости смешаны с виртуальным окружением | ZIP тяжёлый и непереносимый | Код и исходные записи сохранены; .venv создаётся при установке |

## Новые возможности

Новый адаптивный русский кабинет объединяет выбор записи, спектр, временные графики, качество, описательное сравнение, контекст, экспорт и научную базу. В научной базе 25 источников и 22 метрики с условиями применимости. Offline preview содержит реальные результаты и работает без сервера. Все графические библиотеки поставляются локально.

Автоанализ кэшируется, проверяет содержимое файлов по SHA-256, публикует версию метода и работает вне web event loop. Фоновый запуск выполняется после завершения записи. Исходные файлы не переписываются при анализе; пользовательский контекст хранится отдельно и не трактуется как временная разметка.

Интеграционные проверки покрывают кэш и его обновление, изменение файлов во время анализа, контекст и сохранность исходников, strict JSON, три формата экспорта, экранирование HTML, активную запись, параметры, Origin и безопасные пути. API всех трёх исходных сессий проверен через TestClient; это проверка внутри процесса, без аппаратного SDK и браузера.

## Что остаётся ограничением

- Проверка физической повязки и нативного Capsule SDK не выполнялась: поставки SDK и устройства в среде нет.
- Клиническая валидация эвристик не выполнялась. Пороги QC и алгоритм PRV опубликованы, но не заменяют экспертную разметку.
- Истинные единицы, аппаратные timestamp/counter и внутренние фильтры SDK требуют спецификации производителя.
- Нет автоматической очистки ICA, source localization, EEG-диагностики, чтения эмоций или обучения персональной модели по трём неразмеченным сессиям.
- Полноценное браузерное тестирование в текущей среде ограничено недоступностью браузеру локального сервера. API, схема данных и JavaScript проверены программно; это не замена проверке UI на устройстве пользователя.

## Перспективы развития по приоритету

1. Подтверждённые units, scaling, цифровой device counter и отдельное время прибытия пакета.
2. Маркеры условий, task correctness/reaction time, сведения о субъекте и настройке; протокол с повторениями.
3. Экспертно размеченная выборка качества и сопоставление с эталонной системой для настройки QC/PPG.
4. Только после этого — periodic/aperiodic fit, индивидуальные базовые распределения, доверительные интервалы с блочным bootstrap и проверка моделей на отдельных сессиях/людях.
5. Пространственные вопросы — новые многоканальные данные и проверенный forward model, а не интерполяция двух отведений.
