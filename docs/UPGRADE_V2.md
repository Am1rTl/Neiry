# NeuroScope: надёжность устройства и новые исследовательские функции

## Безопасный запуск

```bash
git pull --ff-only
bash start.sh --open
```

Скрипт создаёт локальное виртуальное окружение, при изменении `requirements.txt` обновляет пакеты и открывает интерфейс на `http://127.0.0.1:8000`. Для Windows предусмотрен `start.bat`. Все записи остаются в `records/` и не выкладываются на GitHub. Разделы просмотра архива работают без SDK и без устройства.

Не запускайте сервер на `0.0.0.0` без сетевой защиты. По умолчанию доступ только с этого компьютера. Переменная `NEUROSCOPE_ALLOW_REMOTE=1` разрешает явный экспериментальный сетевой запуск, но **не добавляет аутентификацию**: безопаснее использовать SSH-туннель.

## Исправление аварии `SIGSEGV` при поиске устройств

Причина — Python SDK `DeviceInfoList` реализует `__len__`/`__getitem__`, но не `__iter__` и **не выбрасывает `IndexError` при выходе за пределы**. Код `for entry in info` в CPython обращается к `info[len(info)]` (в том числе `info[0]` для пустого списка). Нативная `clCDeviceInfo_GetName(NULL)` вызывает SIGSEGV, который не перехватывается Python `except`.

Теперь применяется **только** `for index in range(len(info))` с индексной адресацией. Тест `DangerousDeviceInfoList` без `__iter__` проверяет, что ни пустой, ни заполненный список не запрашивает несуществующий элемент. Это устраняет подтверждённый сценарий выхода за границу, **не доказывая полную безопасность сторонней нативной библиотеки**.

По предоставленному crash-логу нативная библиотека также перехватывает `SIGTERM` и вызывает `abort`. Поэтому `stop.sh` отправляет `SIGINT` — как обычный Ctrl+C. `kill -9`, внешние SIGTERM и падения в других функциях SDK всё ещё могут принудительно завершать процесс; для их полноценной изоляции понадобится отдельный процесс-владелец SDK с IPC.

Логи SDK теперь располагаются в явной папке `.runtime/capsule-logs`, а не `~/Logs`, где `~` при передаче в библиотеку не разворачивается оболочкой.

## Устройство и запись

- Поиск запускается явно, не приводит к автоматическому подключению и выбирает серийный номер из результатов.
- Калибровка доступна только после подтверждённого соединения; она необязательна и не блокирует работу с архивом.
- Старт записи отдельной кнопкой требует свежих отсчётов, а не одного только Bluetooth-соединения.
- «Эксперименты» работают только с активной реальной записью: встроенные шаблоны помечают время смены условий, завершаются/прерываются при потере записи. Это **программные маркеры**, не аппаратно-синхронные TTL-события.

## Новые разделы одного интерфейса

- **Живой монитор** — переключаемый масштаб, диагностика помех и контакта, спектрограмма по текущим отсчётам.
- **Записи и replay** — воспроизведение без переполнения памяти, индексный порядок ЭЭГ, пауза и перемотка. Временная синхронизация разнородных потоков старых файлов остаётся оценочной.
- **Исследовать участок** — выбор фрагмента 2–120 секунд, прореживание с сохранением экстремумов, описательные спектральные доли и отдельные ретроспективные метки.
- **Эксперименты** — блоки для спокойного отдыха, глаз открытых/закрытых и задания/восстановления.
- **История** — сравнение только с явно указанным одинаковым псевдонимом, задачей, протоколом и монтажом. Пустой псевдоним не означает одного и того же участника.
- **Исследовательский PDF** — генерируется локально по запросу и работает после чистого `git clone`.

## Исследовательский EEG-BIDS

Для экспорта:

```bash
.venv/bin/python -m pip install -r requirements-research.txt
```

Перед экспортом нужно **самостоятельно подтвердить физические единицы** исходного сигнала (`V`, `mV`, `uV`) по документации конкретного Capsule SDK. Записи с неизвестными единицами не экспортируются как «микровольты по умолчанию». Исходные host timestamp не являются аппаратными временными метками; события старых записей не импортируются как точно синхронизированные. Отсутствующие координаты электродов не выдумываются.

## Новые вычисления

- Многокритериальные инженерные флаги для живого ЭЭГ; они **не являются процентом здоровья мозга**.
- Спектрограмма и локальный PSD с честными единицами исходной шкалы.
- Hjorth activity/mobility/complexity и описательный наклон log PSD только при достаточных прошедших скрининг окнах и отсутствии грубого квантования. Наклон **не равен** параметру апериодического фона из `specparam`.

## Проверка

```bash
python -m pip install -r requirements-dev.txt
python -m unittest discover -p 'test_*.py' -q
node --check static/studio.js
```

Тесты используют эмулятор SDK, а не реальную повязку. После установки обязательно проверьте фактический Bluetooth-скан и остановку сервера на вашей Linux-системе. Crash-лог сохраняйте локально; его и записи нельзя отправлять в публичный репозиторий.
